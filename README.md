# Java 任務管理系統（Java Task Scheduler）

一套使用 Java 開發的任務管理與排程系統，協助使用者建立、管理與追蹤日常任務，提升工作效率與時間規劃能力。

## 專案介紹
本專案為一套任務管理應用，提供任務新增、編輯、刪除與排程管理功能，讓使用者可以更有效率地安排工作流程與管理待辦事項。

此專案展示了 Java 軟體開發實務能力，包含物件導向設計（OOP）、任務流程邏輯設計，以及系統功能模組化開發。

## 主要功能
- 新增任務
- 編輯任務內容
- 刪除任務
- 任務排程管理
- 任務狀態追蹤
- 依時間或優先順序管理任務
- 使用者友善操作介面
- 資料儲存功能（若有實作可保留）

## 適用情境
本系統可應用於：
- 個人待辦事項管理
- 工作排程規劃
- 專案任務追蹤
- 提醒與截止日管理
- 小型工作流程管理工具

## 技術架構
- Java
- 物件導向程式設計（OOP）
-  JavaFX
- MySQL 

## 專案亮點
